# Cryptid Containment: the Field Manual

The built pages of the Field Manual, the strategy guide for the game Cryptid Containment:
https://minormending.github.io/cryptid-containment-guide/

This repository holds **only the generated site**. Every table, picture and number in it is generated from the
game's own data, so it is replaced wholesale on each release. Please do not edit these files by hand.
